## 쓰는 방식

회고 하나에 작업 하나. 이슈마다 아래 순서로 짧게 씀.

1. 이슈: 무엇이 기대와 달랐나
2. 원인 찾기: 어떤 가설을 세우고 어떻게 확인했나
3. 해결: 무엇을 바꿨나
4. 재발 방지: 같은 실수를 구조로 막는 장치
5. 배운 점: 다음에 같은 상황이면 처음부터 어떻게 할까

증상만 막은 경우와 원인을 없앤 경우를 구분해서 적음.
